# kadai11-kobun-quiz-web

プログラミングの授業課題として作成した、アプリの試作です。

## 概要

高等学校の国語科（古典文法）で使う四択形式の文法識別テストです。
手元で SwiftUI により iOS アプリとして開発していたもの（KobunQuiz）を、
Streamlit に移植して Web ブラウザで動くようにしました。

- 収録問題数：778問
- 分野：助動詞の識別／助詞の識別／敬語の種類／文学史

## 機能

- 本文中の対象語を朱色で示し、その文法的説明を四択で問う
- 出題範囲を「分野・小分類から」「出典作品から」「全分野ランダム」の3通りで選択
- 難易度（基礎／標準／発展）と出題数の指定
- 解答直後に正誤と解説を表示
- 終了後、間違えた問題だけをその場で解き直せる

## 選択肢生成の方針（iOS版から引き継いだ設計）

四択の誤答をランダムに選ぶと、たとえば「き」を問う問題に「けり」の説明が混ざり、
本文を読まなくても対象語を見ただけで消去できてしまいます。
それでは識別の練習になりません。そこで次の方針を採っています。

1. 誤答は「同じ小分類・同じ見た目の語が実際に取りうる解答」の中からのみ作る
2. 問題ごとに指定された `requiredDistractors`（教育的に紛らわしい誤答）は必ず選択肢に入れる
3. 選択肢が2つ未満しか作れない問題は「識別が成立しない」ものとして出題しない

なお敬語の問題は選択肢が3つ（尊敬語・謙譲語・丁寧語）になりますが、これは仕様です。

## データについて

`questions.json` は以下の項目を持ちます。

| 項目 | 内容 |
|---|---|
| `text` / `source` | 例文と出典 |
| `target` / `targetStart` / `targetLength` | 問われている語と、本文中での位置 |
| `grammar` | 文法的説明（識別問題の正解） |
| `meaning` | 意味・用法（意味を問う問題の正解） |
| `historyPrompt` / `historyAnswer` | 文学史の設問文と正解 |
| `requiredDistractors` | 必ず選択肢に入れる誤答 |
| `explanation` / `supplement` | 解説と補足 |
| `majorCategory` / `subCategory` / `difficulty` | 分野・小分類・難易度 |

## 個人データの扱い

**解答の記録はサーバに保存していません。** 成績はブラウザのセッション内だけで保持され、
タブを閉じると消えます。公開URLで誰でも開ける状態のまま学習者の解答データを蓄積するのは
適切でないと判断したためです（必要のないデータは最初から集めない）。
その代わり、間違えた問題をその場で解き直す機能を入れ、1回のセッション内で完結する
使い方にしています。

## ローカルでの実行

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## ファイル構成

```
streamlit_app.py        アプリ本体
questions.json          問題データ（778問）
requirements.txt        依存ライブラリ
.streamlit/config.toml  ライトテーマ固定の設定
DESIGN.md               配色・書体などのデザイン定義
```

## 表示について

本文カードや選択肢は明るい背景を前提に配色しているため、
`.streamlit/config.toml` でライトテーマに固定しています。
これが無いと、閲覧者の端末がダークモードのときに見出しと解説文が
暗い背景に暗い文字で表示され、読めなくなります。
